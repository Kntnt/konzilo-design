# Component gallery

read when changing or republishing the live gallery of the built components

An Astro project that renders the real components with invented content. `npm run gallery`, from the repository's root, writes one self-contained page to `gallery/dist/index.html`. The test suite builds it too.

The owner sees it as a private artifact, slug `34c58458-05cd-49cd-bcd9-e98cce0d7cea`. Republish with `publish_files`, giving that file as `index.html` and the live version as `base_version`.

It opens as the tool will, with Mona Sans and the system's monospace (`src/design.js`), while the library's own default stays the system stacks. The design controls switch typefaces and label style live, and the Typefaces section shows every case side by side.
